    \begin{abstract}
        \begin{itemize}
            \item This thesis does not aim to contribute to standard compiler technology. Instead, it focuses on producing assembly instructions for the ISA described in~\cite{sysbook}, without using an intermediate language or virtual machine. Code optimization steps are omitted, and standard building technology can be found in the "Dragon Book" by Aho and Ullman~\cite{dragon}, or in the series of textbooks by Helmut Seidl, Reinhard Wilhelm, and Sebastian Hack~\cite{hsvm,hsaat,hssasa}.
            \item Every component of the project was built from scratch using Java and the Java standard libraries. The authors acknowledge that in real-world applications, one might prefer existing parser generators, such as ANTLR. One of the primary objectives of this thesis was to determine if the C0 grammar, studied and used in the introduction to operating systems class at Kutaisi International University~\cite{sysbook}, could be classified as LR(1). To test whether the C0 grammar is LR(1), we constructed the \(DK_{1}\) automaton presented in Michael Sipser's book~\cite{sipser} and ran the \(DK_{1}\) test on the C0 grammar. It was later discovered that the C0 grammar did not pass the test, thus it is not LR(1). Consequently, we needed to find optimal/minimal changes to make the grammar pass the test and become LR(1). This process would have been significantly more challenging without the corresponding \(DK_{1}\) automaton, as we would not have known which parts of the C0 grammar caused it not to be LR(1) and why. With the implemented \(DK_{1}\) automaton generator and tester, we had a much more powerful tool to adjust the C0 grammar to become LR(1) and to pass the \(DK_{1}\) test.
            \item Another achievement of this thesis is that it demonstrated that based solely on two introductory lectures—introduction to operating systems and introduction to theoretical computer science—it is possible to build a working compiler for a practically useful programming language. The prerequisites for building and understanding the C0 compiler are:
            \begin{itemize}
                \item A single chapter - "Part one: Automata and Languages" from~\cite{sipser}.
                \item Notes about code generation from~\cite{sysbook}.
            \end{itemize}
        \end{itemize}
    \end{abstract}
